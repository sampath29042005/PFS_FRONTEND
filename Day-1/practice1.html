Frontend Development

Frontend developement is the practice of creating the visual(user interface) and interactive(user experience) elements of a website or web application.

User interface (UI) refers to the visual elements that users interact with on a webpage or application.

User experience (UX) refers to the overall experience and satisfaction of users when interacting with a website or application.

Key Concepts

the Key Concepts is used in Frontend Development: 1.HTML(Hypertext Markup Language) 2.CSS(Cascading Style Sheets) 3.JavaScript 4.REACT JS 5.Frameworks

HTML

it is skeleton/foundation of the webpage

HTML is the standard markup language used to create web pages.

CSS

it is used to give the visual appearance to the skeleton/foundations

CSS is a stylesheet language used to describe the presentation and layout of a webpage.

JavaScript

it is used add functionality to skeleton/foundations

it is used to create interactive and dynamic content on web pages

REACT JS

it is a JavaScript library for building user interfaces

it is used to create reusable UI components

Frameworks

Frameworks are pre-built collections of code and tools that provide a structure for building web applications.

Popular frontend frameworks include Angular, Vue.js, and Bootstrap.

Backend Development

Backend development is the practice of creating the server-side logic and functionality of a website or web application.

Key Concepts

the Key Concepts is used in Backend Development: 1.Python or Java 2.Node.js 3.Database management 4.API

Python or Java

Python and Java are popular programming languages used for backend development.

Node.js

Node.js is a JavaScript runtime that allows developers to run JavaScript on the server-side.

Database Management

Database management involves designing, implementing, and maintaining databases to store and retrieve data for web applications.

Common database management systems include MySQL, PostgreSQL, and MongoDB.

API

API(Application Programming Interface) is a set of protocols and tools that allow different software applications to communicate with each other.
